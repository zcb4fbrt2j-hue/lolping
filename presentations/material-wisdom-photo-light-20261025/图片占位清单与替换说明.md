## 在PowerPoint中补图

1. 下载 `.pptx` 后另存一份；使用“开始 → 选择 → 选择窗格”，按表中对象名选中图片占位符。
2. 点击该占位符的图片插入图标（部分版本显示为右键“插入图片”），选取原始照片。请勿拖动其他图片覆盖占位框。
3. 在选择窗格删除同名的 `_LABEL` 文字对象。这是为PDF预览保留的独立提示，删除后不会改变图片位置。
4. 使用“图片格式 → 裁剪 → 填充”，拖动照片调整取景，保留比例，不拉伸。插入完成后的图片可右键“更改图片”继续替换。
5. 将照片的展品名称或拍摄内容、实物/现代复原船/模型性质、拍摄地点、日期、摄影者和许可信息写入页脚或演讲者备注；删除已不适用的“待补充”说明。
6. 保存后重新导出PDF并检查裁剪。若某个PowerPoint版本没有显示插图图标，可用下面的脚本一次插入；此兼容操作已通过程序验证。

## 素材最低要求

- 第1、2、14页建议提供3张独立原片：封面全景、正文结构细节、展品与展签/真实观察现场。同一展品可用不同机位原片，封面原片及其裁剪版本不得进入正文。
- 优先原始宽度≥1920px，建议≥3000px；横向拍摄并为裁剪留余量。展签需另存清晰近照，不要求在投影大图中阅读所有小字。
- 第6、10、13页可以继续暂缺。优先真实的涂层科研、产业转化和本组科研训练场景，照片内容必须与标注一致。一般实验/船厂照片不作为本案例的团队、实验结果或应用证明。
- 不把普通木船标成福船，不把一般施工称为艌缝；身份与性质按展签核实。第14页目前不代表已完成参观。

## 可选：脚本插图（生成新文件）

依赖本环境已安装的 Python `python-pptx` 与 Pillow；脚本只处理你指定的输入副本，不覆盖源文件。它按原生占位符插图并删除对应提示标签，保持几何尺寸。

```bash
python fill_picture_slots.py --input build/material-wisdom-photo-light.pptx \
  --manifest photos.example.json --output material-wisdom-with-my-photos.pptx
```

先复制 `photos.example.json` 并填写真实文件路径和信息。可只提供部分照片，剩余占位符保留。程序检查像素、照片去重与原生占位符几何，无法代替人工判断内容真实性与授权。

已验证：6处占位符均可插入照片，保存并重新打开后位置与裁剪比例不变。测试仅操作 `/tmp` 副本，交付版仍保留空占位。实际Windows/Mac PowerPoint界面尚未人工操作验证。
