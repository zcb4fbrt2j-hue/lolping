# 图片占位框与实拍照片替换

本版只有3页视觉样张（封面、第一章、第四章），传统福船照片尚未拍摄。两个预留区域采用**PPT原生矩形 + 独立可编辑文字标签**，不是背景图片，也不是带“插入图片”按钮的母版图片占位符。

| 页码 | 对象名 | 建议照片 | 裁剪比例 | 位置/尺寸（英寸） | 位置/尺寸（厘米） |
|---|---|---|---|---|---|
| 1 | `MUSEUM_COVER_FUCHUAN` | 身份明确的福船实物、现代复原船或模型整体横向照片，尽量完整保留船体 | **2:1** | X=0.5，Y=2.45；宽4.36，高2.18 | X=1.27，Y=6.223；宽11.0744，高5.5372 |
| 2 | `MUSEUM_BODY_STRUCTURE` | 另一张独立原片：福船结构、模型剖面、隔舱或船板连接细节 | **16:9** | X=0.5，Y=1.89；宽5.65，高3.178125 | X=1.27，Y=4.8006；宽14.351，高8.0724 |

两张可以拍摄同一展品，但应是两个独立机位的原片。封面所有照片及其裁剪、调色、缩放衍生图均不得用于正文或后续12页。最少补充这两张照片；另拍展签有助核验，不作为必须上屏的第三张照片。

## 用 PowerPoint 替换

1. **先另存副本**。打开“开始 → 选择 → 选择窗格”，找到上表对象及同名加 `_LABEL` 的标签；保留位置参照。
2. 插入手机/相机原始照片。使用“图片格式 → 裁剪”调整**裁剪框**至表中比例与尺寸、坐标，再用“填充”并移动画面保留主体。保持原图纵横比；不要取消比例锁定后把照片拉伸到框内。第二页也可直接选择16:9裁剪比例；封面为自定义2:1。
3. 对齐后删除对应矩形和标签。修改图片说明和演讲者备注，补全展品名称与性质、拍摄地点、拍摄日期、摄影者和必要来源。第2页可在图底增加一行简短图注。无需移动全页其他内容。

如果暂不熟悉裁剪，可保留原片和展签，后续交由Codex按已锁定的框位替换。照片清晰度以原始文件为准：优先宽≥1920px，建议≥3000px；避免聊天软件压缩图、截图、玻璃强反光与失焦。照片应留出上下裁剪余量。

**准确标注**：模型称“模型”，现代复原船称“复原船”；只有照片和可靠说明确实证明艌缝操作时才称“艌缝现场”。未实拍前不保证馆内一定展示某件特定展品。遵守馆内拍摄规定，并记录照片允许的使用范围。

## 用已保存的源码按原框位插入

填写 `museum-photos.example.json` 的副本（可只替换一处），将 `file` 指向原片，填入展签身份和拍摄、使用信息；然后运行：

```bash
python presentations/material-wisdom-v3-museum-placeholders/replace_museum_photos.py \
  --manifest 我的实拍照片.json \
  --outdir presentations/material-wisdom-v3-with-museum-photos \
  --dry-run
```

检查通过后移除 `--dry-run` 再运行，再执行新目录中的 `rebuild.sh`。脚本仅更新新目录的 `outline.json`，不会改原始PPTX、V2或当前V3；图片仍走已安装Skill的标准构建器，以等比裁剪放入固定框位。输出目录必须不存在。脚本检查元数据、原图宽度和二进制重复；**不能替代人工对展品身份、清晰度、裁剪后主体和视觉相似衍生图的核验**。新图较长的图注仍须渲染检查。

## 编辑与字体

所有标题、正文、普通图形和照片框可在PowerPoint中编辑。使用字体为 Noto Sans CJK SC；PDF已嵌入所用字形。若本机缺少该字体，建议安装同名字体；若在副本中改用微软雅黑等字体，应检查换行。当前验证环境为LibreOffice，未声称已在Windows PowerPoint做过实机测试。
